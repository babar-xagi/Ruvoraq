# Ruvoraq HTTP adapter

HTTP routing and application lifecycle built on Axum/Tokio. Provides typed
requests, validation, response helpers, consistent errors, shared services,
OpenAPI 3.1 and locally bundled Swagger UI. Applications normally use this
through the public `ruvoraq` facade.

Swagger JavaScript/CSS and their upstream license are included in the package.
No CDN is required to serve the API testing interface.

This is an experimental 0.1.0 release. The framework is developed in verified
increments and is not yet a complete production platform.
